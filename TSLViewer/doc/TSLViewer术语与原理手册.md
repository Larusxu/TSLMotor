## 0. 先记住这五个数

| 数 | 含义 | 用错会怎样 |
|---|---|---|
| **1（极对数）** | 这台电机一对极 → 电角度 = 机械角度 | 极对数填 2，对齐和换相全错 |
| **16384 / 65536** | 编码器 CPR / 每圈 counts（×4 解码） | 位置、速度、行程全部差倍数 |
| **305.4** | 速度寄存器 → RPM 的换算系数 | 目标 300 RPM 变成别的转速 |
| **0.20131 mA/LSB** | 电流分辨率（4× 采样增益） | 电流读数差 4 倍、限幅算错 |
| **25 kHz** | PWM 载波（4800 counts @120 MHz） | 电流环 I 值差一倍、噪声变化 |

## 1. 电机与传动

### 1.1 极对数（pole pairs）

**一句话**：转子上一对 N/S 磁极算一对极；它决定"电角度转一圈，机械只转 1/p 圈"。

**为什么**：FOC 控制的是**电角度**（磁场方向），不是机械角。极对数错了，换相就错，电机会抖、堵转、飞车。

**在本软件**：编码器页「极对数 / PHI_E_MUL_FACTOR」、对齐页、寄存器 `0x100[6:0]`。Tesla 手电机 = **1**。

**别搞错**：极对数 ≠ 极数。4 极电机是 **2 对极**。名字里写"4 极"就填 2。

### 1.2 电角度 φ_e（electrical angle）

**一句话**：转子磁场当前指向，360° 电角 = 转一圈磁极。

**为什么**：FOC 要把电流矢量始终垂直于转子磁场才有最大力矩，所以必须实时知道 φ_e。

**在本软件**：编码器页「ELECTRICAL」仪表（`0x251`，0–65535 对应 0–360°）、对齐页的扫描角度。

**别搞错**：φ_e 会随转子转动快速变化——300 RPM、1 对极时电角度每秒转 5 圈。

### 1.3 机械角 vs 电角

**一句话**：机械角是转子真实转过的角度；电角是它乘上极对数。

```
φ_e = 机械角 × 极对数
```

**为什么**：编码器装在外面，测的是机械角；芯片要的是电角。两者靠 `PHI_E_MUL_FACTOR`（极对数）和 `0x242`（偏移）建立关系。

**在本软件**：编码器页两个仪表并排显示，一眼能看出倍数关系（p=1 时两者同速）。

**别搞错**：对齐做的事就是找那个**偏移**，不是找倍数——倍数由极对数决定。

### 1.4 CPR 与 counts

**一句话**：CPR = 编码器每圈多少个脉冲；counts = 芯片内部计数单位（本项目 = CPR × 4）。

```
16384 CPR × 4 = 65536 counts/圈
```

**为什么**：芯片用 4 倍频解码（A/B 两相各两个边沿），精度是 CPR 的 4 倍。位置、速度、行程全以 counts 为基准。

**在本软件**：编码器页「编码器步数 CPR」；机械行程页「每圈计数 65536」；位置 `0x155`。

**别搞错**：`0x155` 只有 **16 位**，超过 65535 就回绕——这就是要做[多圈展开](#15-多圈展开)的原因。

### 1.5 多圈展开（unwrap）

**一句话**：把"每圈归零"的 16 位位置，连成一条不会回绕的连续位置线。

**为什么**：丝杆 20 mm 行程 / 2 mm 导程 = 转 10 圈 = 位置计数回绕 10 次。直接用 16 位值，第一圈之后软限位就会误判。

**在本软件**：机械行程页的后端逻辑。相邻两帧差值累加：

```
Δ = raw[n] − raw[n−1]
Δ > 32768  → Δ −= 65536     （正向跨零）
Δ < −32768 → Δ += 65536     （反向跨零）
pos += Δ
```

前提：相邻两帧位移 < 半圈。1 kHz 采样下半圈/帧 = 30000 RPM，远高于电机上限，**不会误判**。

**别搞错**：一断电就归零。这是"上电必须回零"的物理原因——不是软件偷懒。

### 1.6 导程 / 行程 / 原点 / 回零

| 词 | 定义 | 例子 |
|---|---|---|
| **导程（lead）** | 丝杆转一圈，滑块走多少 mm | 2 mm/转 |
| **有效行程** | 两端死点之间的可用距离 | 20 mm |
| **原点（home）** | 约定的 0 位，一般取缩回端死点 | counts 值 |
| **回零（homing）** | 用某种方式找到并锁定原点 | 见 6.4 |

**为什么**：电机只认 counts，人只认 mm。这四个数就是两套坐标之间的桥：

```
每毫米 counts = 65536 / 导程 = 32768（导程 2 mm 时）
mm = (pos − 原点) / 32768
```

**在本软件**：机械行程页「丝杆换算」卡；行程条上的 0 / 半程 / 全程刻度。

**别搞错**：导程填错一倍，所有 mm 值都错一倍，而且**软限位窗口也会错一倍**——这是撞机最常见的原因。

### 1.7 机械死点与背隙

**一句话**：死点是撞不动的硬限位；背隙是换向时先空走的那一小段。

**为什么**：
- 死点：只能用"堵转 + 低力矩"去碰，不能高速撞；
- 背隙：换向后位置会先丢一段，所以**定位容差不能设得比背隙还小**，否则永远"到不了位"。

**在本软件**：死点靠软限位的安全边距躲开；背隙体现在定位容差（默认约 0.03 mm 折算）。

**别搞错**：正反转定位精度天然不对称，别拿单向数据当双向精度。

## 2. 电流、电压与调制

### 2.1 Id / Iq（磁链 / 力矩分量）

**一句话**：把三相电流旋转投影到转子上，得到两个直流量——`Id` 对齐磁场（不产生力矩），`Iq` 垂直磁场（产生力矩）。

**为什么**：三相正弦电流没法直接做 PI 控制（一直在变），投影成两个直流量后就能用普通 PI 了。

**在本软件**：
- 运行概览 KPI「力矩电流 iQ」（`0x153` 高 16 位）；
- 阶跃测试可选「电流环 iD」；
- PID 页「电流环 · 力矩 / 磁链」对应 `0x143`（Iq）/ `0x142`（Id）。

**别搞错**：`0x153` 一个寄存器装两个量，高低 16 位分别是有符号数。软件已经拆好了，但你自己用寄存器页看时要注意。

### 2.2 Clarke / Park 变换

**一句话**：Clarke 把三相 → 两相静止（αβ）；Park 再把两相静止 → 两相旋转（dq）。

**为什么**：这是 FOC 的数学骨架。芯片内部完成，用户不需要算，但**看懂 Iq 的含义必须知道这层**。

**在本软件**：不可见（芯片内），只体现在 `0x168 IQ_ID`、`0x169 UQ_UD` 这些"已经是 dq 量"的寄存器上。

**别搞错**：dq 量是**旋转坐标系**的，不是某一相的瞬时值。

### 2.3 Uq / Ud 与调制比

**一句话**：`Uq/Ud` 是控制器最终算出的电压矢量，调制比表示它占母线电压的多少。

| 值 | 含义 |
|---|---|
| 18900 | **100% 调制**（线性区上限） |
| 23169（`0x5A81`） | 出厂电压限幅，含过调制余量（约 122%） |

**为什么**：电压不够就推不动电流；但超过 100% 调制会失真、产生低频谐波。限幅既保安全也保波形质量。

**在本软件**：PID 页「电压限幅」会实时显示百分比；「单位换算」卡里写明 18900 = 100%。

**别搞错**：把限幅调得很高并不会让电机更有力——真正的上限是母线电压和电流限幅。

### 2.4 SVPWM 与载波频率 fPWM

**一句话**：用 6 个开关的组合把直流切成三相正弦，切换频率就是载波频率。

**为什么**：载波越高，电流纹波越小、声音越尖；载波越低，开关损耗越小但纹波大、可能听到啸叫。

```
fPWM = 120 MHz / MAX_COUNT = 120 MHz / 4800 = 25 kHz
```

**在本软件**：编码器页「PWM MAX_COUNT」；侧栏底部「PWM 25.00 kHz」；PID 页「PWM 频率」。

**别搞错**：改载波等于改**整个控制环的时基**——电流环积分项、测速配置、RTMI 采样率全部跟着变。非必要不要动。

### 2.5 CSA 与 mA/LSB

**一句话**：CSA 是电流采样放大器，增益决定"1 个 LSB 代表多少安培"。

```
增益 4×（0x0C3 = 3）：0.20131 mA/LSB，8192 LSB ≈ 1.65 A
增益 1×（0x0C3 = 0）：约 0.805 mA/LSB，同样 8192 LSB 就是 6.6 A
```

**为什么**：所有电流读数、力矩限幅、保护阈值都基于这个系数。**差 4 倍是这套板子最经典的坑**——遗留固件会把 `0x0C3` 写成 0。

**在本软件**：编码器页「CSA 增益」+ 写入校验表里的 `0x0C3` 回读；PID 页「电流分辨率」。

**别搞错**：换增益不会让电机变有力，只会改变"读数与限幅的对应关系"。

### 2.6 力矩常数

**一句话**：力矩 ≈ 力矩常数 × Iq。

**为什么**：速度环输出的"力矩指令"其实是一个电流指令，中间靠这个常数换算。所以**限流就是限力矩**。

**在本软件**：力矩限幅 `0x14A`（800 mA）就是这条链路的总闸。

**别搞错**：堵转时电流顶限幅 ≠ 力矩够用——可能只是限幅设高了，或摩擦太大。

## 3. 控制环与增益

### 3.1 开环 / 闭环

| | 开环 | 闭环 |
|---|---|---|
| 依据 | 按设定电压/电流硬推 | 看反馈误差再修正 |
| 特点 | 简单、会随负载跑偏 | 抗扰、能精确跟随 |
| 用在哪 | 电角度对齐、自动测试的"开环电压"档 | 转速、位置 |

**在本软件**：对齐页就是开环（用电流把转子拽到已知电角）；速度闭环卡是闭环；自动测试可选开环模式做对比。

### 3.2 级联三环

```
 位置环 P/I (0x146) ──▶ 速度环 P/I (0x145) ──▶ 电流环 P/I (0x142/0x143) ──▶ 功率级
      慢（外）                中                       快（内）
```

**为什么**：越内环越快、越外环越慢。内环稳了外环才可能稳；内环没调好就调外环，等于在晃的地基上盖楼。

**在本软件**：PID 页三个并列卡片，从左到右就是内→外。

**别搞错**：调参顺序**永远从电流环开始**。

### 3.3 P / I / D 各自在管什么

| 项 | 作用 | 太大 | 太小 |
|---|---|---|---|
| **P** | 按当前误差出力 | 振荡、尖叫、过冲 | 反应慢、稳态差 |
| **I** | 累积历史误差 | 超调、低频晃动、积分饱和 | 永远差一点、跟随滞后 |
| **D** | 按误差变化率出力 | 放大噪声（本项目默认不用） | — |

**在本软件**：三个环都只有 P/I（`D` 一般不启用；速度环/位置环的 I 也可置 0 变纯 P）。

### 3.4 带宽（bandwidth）

**一句话**：闭环能跟上的最高频率，数字越大反应越快，也越容易受噪声影响。

**为什么**：带宽是"性能与稳定"的旋钮。电流环带宽常取载波的 1/10 左右（25 kHz → 2 kHz 量级）。

**在本软件**：阶跃测试页的「带宽」字段（默认 2000 Hz），只用于**反算建议 PI**，不直接写芯片。

**别搞错**：填 2000 Hz 不会让硬件变成 2 kHz 带宽，它只是算 P/I 的参考。

### 3.5 Q 格式 / Shift by n

**一句话**：寄存器里存的是整数，真实增益 = 整数 × 2⁻ⁿ。

| 归一化 | 缩放 | 64 表示 |
|---|---|---|
| `No shift（Q16.0）` | ×1 | 增益 64 |
| `Shift by 8 / Q8.8` | ÷256 | 增益 **0.25** |
| `Shift by 16 / Q0.16` | ÷65536 | 增益 0.00098 |

**为什么**：定点芯片没有小数，只能用移位表示小数增益。归一化说错一位，增益就差 2 的幂次。

**在本软件**：PID 页每个环都有「P 归一化 / I 归一化」下拉，卡片底部实时显示换算后的 `Kp / Ki`。

**别搞错**：**这是最容易烧管子的地方**——把 Q8.8 的 64/48 写进 Q16.0，实际增益放大 256 倍。

### 3.6 积分器与抗饱和

**一句话**：积分器是 I 项的"记忆"，限幅后还在累积就会"记住"一个永远追不上的值。

**为什么**：堵转时误差一直存在，积分器会涨到很大；一旦松开，要很久才退回来 —— 表现为"松手后还在冲"。

**在本软件**：PID 页写入时**会清四个积分器**（`0x15D/0x15E/0x15F/0x160`）；急停也会清。

**别搞错**：手动改寄存器调参后不清积分器，之前的旧值会继续起作用。

### 3.7 限幅与饱和

四种限幅，各管一段：

| 限幅 | 寄存器 | 作用 |
|---|---|---|
| 力矩/磁链 | `0x14A` | 电流环输入的最大值 → 限制最大出力 |
| 速度 | `0x14B` | 速度环输入的最大值 → 限制最大转速 |
| 电压 | `0x149` | 输出矢量最大值 → 限制调制深度 |
| 位置偏置 | `0x140` | 输出右移、降采样等结构性参数 |

**在本软件**：PID 页「限幅与开关」行。

### 3.8 前馈 / 斜坡发生器

**一句话**：不等误差出现就提前给一部分输出，或把阶跃变成斜坡。

**为什么**：纯反馈永远"先错再改"。斜坡（RAMPER）让速度/位置平滑爬升，减小冲击与超调。

**在本软件**：寄存器 `0x1C4…0x1D1`（RAMPER 组）。目前界面没有专门调它，`0x1D0 斜坡速度` 只作为可选观测量。

**别搞错**：软件里的"梯形定位"是上位机自己规划的加速度，不是芯片 RAMPER。

## 4. 阶跃响应（重点）

### 4.1 阶跃是什么

**一句话**：把一个量**瞬间**从 0 加到某个值，看系统怎么追上去、有没有冲过头、最后停在哪。

```
目标值 ─┐
        └──────────────────
                实际值：   ╭───╮
                          ╱     ╲___
                         ╱     过冲  ╲___ 稳态误差
                        ╱
                   上升时间
```

**为什么**：阶跃是**最便宜的"体检"**。给一次小阶跃（500 mA，不足以带动负载），就能看出这个环的 P/I 配得合不合适、有没有振荡倾向、延迟有多大——不用等到整机上跑高速才发现问题。

### 4.2 为什么不用"正弦扫频"或"随便跑一下看看"

| 方法 | 优点 | 缺点 |
|---|---|---|
| 阶跃 | 一次采集就能看全（快、便宜、可重复） | 只反映小信号行为 |
| 扫频 | 能画完整 Bode 图 | 需要专用设备、耗时长 |
| 随便跑 | 直观 | 不可重复、说不清好坏 |

阶跃是工程上"够用且可复现"的那一个。

### 4.3 六个指标

| 指标 | 定义 | 电流环参考 | 速度环参考 |
|---|---|---|---|
| **上升时间** | 10% → 90% 所用时间 | 8–12 ms | < 80 ms |
| **调节时间** | 进入 ±5% 并不再出去的时间 | < 30 ms | < 300 ms |
| **超调** | (峰值−目标)/目标 | < 5% | < 10% |
| **稳态误差** | 稳定后与目标的偏差 | < 2% | < 2% |
| **纹波** | 稳态段的峰峰值 | 小且不规律 | 小且周期性 |
| **峰值** | 实际达到的最大值 | 接近目标 | — |

**为什么关心超调**：定位时超调 = 冲过头。行程只有 20 mm、边距 0.5 mm 时，**10% 超调就足以撞到限位**。

### 4.4 从曲线判断该调 P 还是 I

| 曲线长相 | 说明 | 动作 |
|---|---|---|
| 慢悠悠爬上去，长期差一点 | P 不足、I 不足 | 加 P；还差再 +I |
| 冲很高再慢慢回来（低频晃） | I 太大 | 减 I |
| 高频抖动、毛刺 | P 太大 / 噪声大 | 减 P |
| 一上来就顶到限幅再回来 | 幅度太大或前馈缺失 | 减小阶跃幅度再看 |
| 有稳态误差但很平稳 | 纯 P（I=0） | 加一点 I |
| 上升快但立刻掉、反复 | 归一化可能有误 | 先核对 Q 格式 |

### 4.5 本软件的阶跃是怎么做的

1. 写入当前环的系数（确保测的是"要验的那组参数"）；
2. 进入对应模式，启动 RTMI（1 kHz 采目标值与实际值）；
3. 注入阶跃：延时后把目标从 0 跳到设定幅度；
4. 采集固定时长（默认 1500 ms），停止输出；
5. 计算指标，并把 1 kHz 原始点**重采样到 900 点**画图（屏幕宽度约 900 px，1:1 显示最清楚）。

**为什么只有 1 kHz**：受串口带宽限制（115200 下 4 通道 × 5 B ≈ 1.7 ms/帧）。想测更快的电流环瞬态，需要把波特率提到 921600 以上。

**在本软件**：PID 页「阶跃测试」+「阶跃响应」两张卡；曲线下方给出 P/I/采样点数。

**别搞错**：
- 阶跃测的是**闭环小信号**，不代表大负载下的表现；
- 采到的"实际值"是编码器/电流的**反馈量**，不是指令；
- 曲线只有 900 点，细节被压过——要看原始点去日志/CSV。

## 5. 反馈与通信

### 5.1 SSI 与 SPI 模式（CPOL / CPHA）

**一句话**：SSI 是"主机给时钟、从机吐数据"的同步串行协议；模式 1 = 时钟空闲低、下降沿采样。

**为什么**：MT6701 的数据在**时钟上升沿更新**，所以主机要在**下降沿**采样（CPHA=1）。模式选错，读到的就是错位一位的数据——角度会跳。

**在本软件**：编码器页「SPI 模式 / CPOL·CPHA」，预设已固定模式 1。

**别搞错**：模式 0 也能"读出数"，但数值是错的，且看起来"好像有变化"，非常迷惑。

### 5.2 MT6701 的 24 拍帧

```
D13…D0（14 位角度） │ Mg3…Mg0（4 位状态/报警） │ CRC5…CRC0（6 位校验）
        ↑ 高 14 位就是 14-bit 预设取的部分
```

**为什么**：只要角度的话，前 14 拍就够（遗留固件就是这么用的）；要报警和校验就得读满 24 拍。

**在本软件**：编码器页「帧长度」14 bit / 24 bit 两个预设；`PHI_EXT_A` 会显示原始字。

**别搞错**：24 bit 时 `PHI_EXT_A` 是 24 位原始字，`CPR_INV` 的算法与 14 bit 不同——不确定就用 14 bit 预设。

### 5.3 CRC

**一句话**：校验位，用来判断这一帧数据在传输中有没有被打坏。

**为什么**：SSI 是板内短距离，一般不会错；但强干扰下会偶发翻转，必须能识别。

**在本软件**：MT6701 用 6 位 CRC（多项式 x⁶+x+1）；TMC6460 的 UART 也有可选 CRC-8（0x1D）。软件会算，但默认不开（与厂商工具一致）。

**别搞错**：CRC 只能"发现"错误，不能"纠正"错误。

### 5.4 RTMI

**一句话**：芯片的"实时数据推送"——你告诉它采哪些寄存器、每隔多少周期采一次，它主动往串口吐。

**为什么**：轮询读寄存器要一来一回（几毫秒），采不到 1 kHz；RTMI 是单向推送，能跑满带宽。

```
触发率 = fPWM / (sampling + 1)
25 kHz / 25 = 1 kHz（sampling = 24）
```

**在本软件**：运行概览的「信号通道」配置 + 「开始采集」；底部显示实测帧率与 sampling。

**别搞错**：RTMI 帧里没有地址，只有"第几个通道"——所以通道配置一旦改了必须重启数据流。

### 5.5 采样率、带宽与混叠

**一句话**：采样率必须远高于你要看的现象的变化速度，否则会"看错"（混叠）。

**为什么**：1 kHz 采样看 100 Hz 的现象够用；想看电流环 10 ms 级的瞬态，1 kHz 刚好卡在边缘。奈奎斯特定理只保证"不混叠"，工程上通常要 5~10 倍余量。

**在本软件**：采样率下拉（250–4000 Hz）+ 黄色带宽提示。

**别搞错**：采样率提到 4 kHz 但串口撑不住 → 丢字节 → 波形出现规律的断点，比低采样率更糟。

### 5.6 丢弃字节 / 丢帧

**一句话**：解析器认不出的字节数，说明数据流被截断或被打乱。

**为什么**：串口带宽不够、写入事务打断了流、线太长/干扰，都会造成丢帧。

**在本软件**：示波器底部「丢弃 0 字节」。**不为 0 就要处理**（降采样率、提波特率、缩短线、加共地）。

### 5.7 为什么要"写后回读"

**一句话**：这颗芯片的写操作默认不回应，只能靠读回来确认。

**为什么**：只有当 `UART.RTMI_CH_7.CH_7_EN = 1` 时芯片才回写应答；否则写完就是"石沉大海"。所以软件所有关键写入都跟一次读回校验，不一致就在日志里标 warn。

**在本软件**：编码器页的「写入校验表」就是这件事的可视化；寄存器页每次写入也默认校验。

**别搞错**：日志里出现"校验失败"不代表没写进去——可能是写进去了但读回被 RTMI 帧干扰，重试一次通常就好。

## 6. 位置与行程保护

### 6.1 软限位（soft limit）

**一句话**：用软件规定的"允许活动范围"，越界就自动停。

**为什么**：机械死点撞一次可能就坏了。软限位把"撞"变成"提前停"，且可以随时改（换机构不用改硬件）。

**在本软件**：机械行程页「行程保护」卡，范围以 counts 存后端，**每收到一帧位置就检查一次**（1 kHz 级）。

**别搞错**：
- 软限位依赖位置反馈，**反馈断了就没保护**（软件因此会拒绝运动）；
- 软限位不能替代机械限位块和硬件急停。

### 6.2 硬限位

**一句话**：物理挡块 + 限位开关，撞到就断电/停机。

**为什么**：软件会死机、会掉线、会被人改参数；硬限位是最后一道防线。

**在本软件**：不参与（当前 `IO_MATRIX` 没有配置限位输入）。

**别搞错**：装了软限位不等于可以不装硬限位。

### 6.3 堵转检测

**一句话**：靠"速度掉到 0 但电流顶满"判断电机被挡住了。

**为什么**：没有限位开关时，这是唯一能自动知道"到头了"的办法。

**在本软件**：**目前没有**（回零向导靠人看转速和位置）。做的时候需要同时采 `0x154 实际转速` + `0x153 力矩电流`，判据大致是：

```
|转速| < 3 RPM  且  电流 > 限幅×85%  连续 ≥150 ms  →  判堵转
再结合"距预期端点 <10% 行程" → 判到位；否则判卡滞
```

**别搞错**：只用速度判会误判（低速本来就近 0）；只用电流判也会误判（加速瞬间电流也大）。

### 6.4 回零（homing）的三种方式

| 方式 | 原理 | 精度 | 需要什么 |
|---|---|---|---|
| **撞死点** | 低速顶到机械限位，把该位置记成原点 | 中（受弹性变形影响） | 低力矩 + 到点判据 |
| **限位开关** | 触发开关的瞬间记原点 | 高 | 一个 GPIO 输入 |
| **绝对多圈编码器** | 断电也知道位置，无需回零 | 最高 | 换多圈绝对值编码器 |

**为什么必须回零**：MT6701 是**单圈绝对值**，只能告诉你"在本圈多少度"，不知道已经走过几圈。断电后多圈信息丢失 → 每次上电都要重新回零。

**在本软件**：机械行程页「回零向导」（撞死点法，当前为人工四步）。

**别搞错**：回零时**必须先把力矩限幅降下来**（如 800 → 200 mA），否则是拿满力顶死点。

### 6.5 安全边距（margin）

**一句话**：在真正的死点前面留一段"不进入"的距离。

**为什么**：定位会超调、机构会热胀、原点会有一点点偏移。边距就是给这些误差留的余量。

**在本软件**：机械行程页「安全边距」，**只从远端扣**。

**别搞错**：为什么近端不扣——因为近端就是原点，开机时电机就停在那儿；近端再扣一段，一上电就"站在窗口外"，软限位反而写不进去。

### 6.6 越限动作：松力矩 vs 刹车

| 动作 | 做什么 | 适用 |
|---|---|---|
| **松力矩（保持）** | 目标写 0、清积分器，仍通电 | 水平丝杆、有自锁；能立刻继续操作 |
| **刹车（PWM_OFF）** | 关 PWM + 清驱动使能 | 垂直轴、可能被负载拖动；但轴会自由滑动 |

**为什么**：越限时"停住"和"断电"是两件事。垂直轴断电会掉下来，水平丝杆断电反而要重新使能。

**在本软件**：行程保护卡「越限动作」下拉。

### 6.7 反馈中断拒动

**一句话**：软限位开着但没数据时，运动指令直接被拒绝。

**为什么**：没有反馈的"保护"是假保护——电机照转，越界也没人知道。宁可不走，也不盲走。

**在本软件**：`axis_jog` / `axis_move` 会先检查 RTMI 是否在该通道上跑，不满足直接返回错误。

## 7. 速度与位置规划

### 7.1 梯形速度曲线

**一句话**：加速 → 匀速 → 减速，三段拼成一个梯形。

```
v
│      ┌────────┐
│     ╱          ╲
│    ╱            ╲
└───┴──────────────┴──▶ t
   加速   匀速    减速
```

**为什么**：直接跳变会让机械受冲击、丢步、超调。梯形是最简单可靠的规划。

**在本软件**：机械行程页「定位」用梯形规划，每 30 ms 更新一次速度目标：

```
v = min(v_max, √(2·a·剩余距离))
```

这个式子的含义是：**任何时刻的速度都保证还来得及在剩余距离内刹住**——所以它天然不会冲过头。

### 7.2 加速度 a*（给定加速度）

**一句话**：带星号的量表示"给定值/指令值"（欧系伺服写法：n\* 给定转速、i\* 给定电流、a\* 给定加速度、φ\* 给定角度）。

**为什么**：控制里"想要的"和"实际的"必须分清楚。`v` 是实际速度，`v*` 是你要的速度；`i` 是实测电流，`i*` 是指令电流。

**在本软件**：界面用中文"目标转速/速度上限/加速度"，没直接用星号；但**看芯片手册、别的伺服资料时会大量出现星号写法**，见到就把 `x*` 读成"给定的 x"。

**别搞错**：加速度单位是 **counts/s²**（不是 mm/s²）。20 mm 行程常用 300000–500000。

### 7.3 容差与"到位"

**一句话**：进入目标 ±容差就算到，不再纠。

**为什么**：编码器有噪声、机构有背隙，要求"绝对等于"会导致来回微调（抖）。

**在本软件**：定位时容差默认取 `0.03 mm` 折算的 counts；`done` 徽标表示已到位。

**别搞错**：容差不能小于背隙，否则永远"到不了位"。

### 7.4 超调为什么会撞限位

**一句话**：定位冲过目标的那一段，如果目标和限位之间没有足够余量，就撞上了。

**为什么**：超调量 ≈ f(速度, 减速度, 环带宽)。速度越高、减速度越小，冲得越远。

**在本软件**：这就是"安全边距 ≥ 2×超调量"和"第一次定位一定要低速"的原因。

## 8. 符号与单位约定

### 8.1 带 `*` 的量（给定值）

| 写法 | 读法 |
|---|---|
| `n*` / `v*` | 给定转速 / 给定速度 |
| `i*`、`iq*`、`id*` | 给定电流 |
| `a*` | 给定加速度 |
| `φ*`、`φe*` | 给定（电）角度 |
| `T*` | 给定力矩 |

**为什么**：不加星号的是**实测**，加星号的是**指令**。看波形时两者分开画，才能看出跟随误差。

**在本软件**：示波器里的「实际转速」= 实测，「目标转速」= 给定（即星号量）。

### 8.2 下标约定

| 下标 | 含义 |
|---|---|
| `q` / `d` | 交轴（产生力矩）/ 直轴（产生磁链） |
| `act` | actual，实测 |
| `tgt` | target，目标 |
| `ext` | external，外部编码器 |
| `e` | electrical，电角度 |
| `max` / `lim` | 上限 / 限幅 |

### 8.3 单位与进制

| 写法 | 含义 | 注意 |
|---|---|---|
| counts / LSB | 芯片内部计数单位 | 位置、速度、电流都用它 |
| `0x242` | 十六进制地址 | 界面里地址与值都是 hex |
| `Q8.8` | 定点格式（8 位小数） | 与"Shift by 8"是同一件事 |
| `RPM` | 每分钟转数 | 机械转速 |
| `mA` | 毫安 | 电流（不是 A，别差 1000 倍） |
| `counts/s²` | 加速度 | 定位参数用 |

### 8.4 速度寄存器到底怎么换算

```
RPM = 速度寄存器值 / 305.4
寄存器值 = RPM × 305.4
```

**为什么是 305.4**：这个系数由 `0x244 / 0x245`（测速配置）决定，本项目沿用遗留固件的实测值。

**别搞错**：**不要把速度寄存器当成 counts/s**。1 转/秒对应寄存器 65536 是巧合级别的相似，实际换算是按 305.4 走的（例：25000 RPM 上限 = 7 635 000）。

## 9. 十条常见误解

| # | 以为 | 其实 |
|---|---|---|
| 1 | 极对数就是极数 | 极数 ÷ 2 才是极对数 |
| 2 | 编码器 16384 就是每圈 16384 counts | 芯片 4 倍频后是 65536 |
| 3 | 位置寄存器能一直数下去 | `0x155` 只有 16 位，每圈归零 |
| 4 | 断电后位置还在 | 单圈绝对值 + 软件累加，断电即失，必须回零 |
| 5 | PID 填 64/48 就是 Kp=64 | 要看归一化；Q8.8 下是 0.25 |
| 6 | 电流读数是 A | 是 mA；且随 CSA 增益变，差 4 倍是常见事故 |
| 7 | 力矩限幅调高就有力 | 真正的上限是电流与母线电压 |
| 8 | 软限位等于安全 | 反馈断了就没保护，也不能替代硬限位 |
| 9 | 采样率越高越好 | 超过串口带宽会丢帧，波形更糟 |
| 10 | 回零随便顶一下就行 | 满力矩顶死点会顶坏丝母，且原点带弹性变形误差 |
