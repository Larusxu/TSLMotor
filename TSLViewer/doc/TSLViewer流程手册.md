## 1. 全局概览

### 1.1 从一块新板到能量产：一张总图

```
 ┌───────────┐   ┌───────────┐   ┌───────────┐   ┌───────────┐
 │ 0 机械/电气 │──▶│ 1 通信连机 │──▶│ 2 编码器   │──▶│ 3 电角度   │
 │   自检     │   │  CHIP.ID  │   │  配置+验证 │   │   对齐 φ_e │
 └───────────┘   └───────────┘   └───────────┘   └───────────┘
                                                        │
   ┌────────────────────────────────────────────────────┘
   ▼
 ┌───────────┐   ┌───────────┐   ┌───────────┐   ┌───────────┐
 │ 4 低速闭环 │──▶│ 5 PID 整定 │──▶│ 6 行程保护 │──▶│ 7 产测    │
 │   试转     │   │  电流→速度 │   │  回零+限位 │   │  CSV 报告 │
 └───────────┘   └───────────┘   └───────────┘   └───────────┘
```

**四个必须守住的"关卡"**（上一关没过，绝不进下一关）：

| 关卡 | 通过标志 | 没过就往下做的后果 |
|---|---|---|
| ② → ③ | 手转电机，`PHI_EXT_A` 明显变化 | 对齐拟合全是噪声，写回的偏移比原来更糟 |
| ③ → ④ | 对齐 R² > 0.99 | 闭环一转就抖、飞车、堵转 |
| ④ → ⑤ | 100 RPM 试转跟随良好 | 调 PID 时不知道是参数问题还是标定问题 |
| ⑥ → ⑦ | 越界能自动停 | 产测时撞机械死点，损坏丝杆 |

### 1.2 流程分三层

| 层 | 内容 | 谁负责 |
|---|---|---|
| **策略层** | 什么时候该做哪条流程（首次上电？换电机？故障恢复？） | 本文第 1 章 |
| **操作层** | 每条流程内的具体步骤与界面动作 | 本文第 2~7 章 + 《操作手册》 |
| **判据层** | 每步的量化通过标准与失败分支 | 本文第 8 章（汇总表） |

### 1.3 六条主流程索引

| 编号 | 流程 | 触发条件 | 预计耗时 | 主入口页面 |
|---|---|---|---|---|
| A | 首次上电（从零到能转） | 全新板子 / 全新电机 / 全新装配 | 40~60 min | 运行概览 |
| B | 换电机 / 换编码器（重标定） | 只换电机：重跑对齐；换编码器：全套重来 | 10~40 min | 对齐与闭环 |
| C | 装丝杆 → 行程标定 → 回零 | 机械机构装好、要开始用位置控制 | 20~30 min | 机械行程 |
| D | PID 整定 | 试转跟随差 / 抖动 / 异响 / 换负载 | 30~90 min | PID 与限幅 |
| E | 出厂测试与报告 | 每台电机的例行验收 | 3~5 min/台 | 自动测试 |
| F | 故障恢复 | 急停、越限、通信中断、参数写坏 | 2~10 min | 运行日志 |

**日常产线只用 E**；A 是一次性的；B/C/D 只在硬件变化时做。

### 1.4 设备状态机

```
   离线
    │  连接（读 CHIP.ID 成功）
    ▼
  已连接 ────────────────────────┐
    │  编码器配置 + 回读 OK       │ 断开/急停
    ▼                            │
  已配置 ────────────────────────┤
    │  对齐成功、0x242 已写       │
    ▼                            │
  已标定 ────────────────────────┤
    │  限幅核对 + PID 核对        │
    ▼                            │
  可闭环 ────────────────────────┤
    │  回零 + 写软限位            │
    ▼                            │
  可生产（有保护）─── 急停/断电 ──┘
```

| 状态 | 允许 | 禁止 |
|---|---|---|
| 已连接 | 读寄存器、写寄存器 | 开环力矩、闭环、运动 |
| 已配置 | 读角度、干跑对齐 | 正式闭环 |
| 已标定 | 低速闭环试转 | 高速运行、定位 |
| 可闭环 | 转速运行、PID 阶跃 | 位置定位（无限位保护） |
| 可生产 | 全部功能 | — |

> 断电即回"离线"。**除芯片里的寄存器值外，软件不保存任何状态**（原点、导程等需重新输入）。

## 2. 流程 A：首次上电（从零到能转）

### 2.1 局部概览

```
 A0 机械/电气自检 ─▶ A1 连机 ─▶ A2 读现状 ─▶ A3 编码器配置 ─▶ A4 角度验证
                                                                   │
                             ┌─────────────────────────────────────┘
                             ▼
                    A5 φ_e 对齐 ─▶ A6 低速闭环 ─▶ A7 PID 核对 ─▶ A8 行程保护 ─▶ A9 产测
```

**本章要点**：A0~A2 只读不动车；A3 会改引脚复用；**A4 是 A5 的前置条件**；A6 是第一次让电机自己转，手必须放在急停上。

### 2.2 分步执行

| 步 | 目的 | 入口 | 关键操作 | 判据 | 失败分支 |
|---|---|---|---|---|---|
| **A0** | 不带着隐患上电 | 机械 | 电机固定、联轴器锁紧、电源限流（建议 ≤1 A）、手转一圈 | 无卡滞、无刮擦声、编码器线不干涉 | 机械处理后再来 |
| **A1** | 确认板子活着 | 顶栏 | 选串口 → 连接 | 日志出现 `CHIP.ID = 0x64600001` | → F1 |
| **A2** | 摸清现状 | 运行概览 | 看「驱动状态」卡：运动模式、极对数、供电 VM | 极对数 = 1；VM 在额定范围；模式为 `PWM_OFF` | 极对数不对 → 到寄存器页查 `0x100` |
| **A3** | 让芯片读得到角度 | 编码器 | 选 `MT6701 · SSI 14-bit（台架已验证）` → 勾选确认 → 写入编码器配置 | 写入校验表 5 行全 OK；`0x0C3` 回读 = 3 | 出现「差异」→ 见第 8 章第 3 行 |
| **A4** | 证明编码器真的在动 | 编码器 | **手转电机轴**，看「角度回读」 | `MECHANICAL` 角度连续变化；`PHI_EXT_A` ≠ 0 | `PHI_EXT_A = 0` → 见第 8 章第 4 行 |
| **A5** | 建立转子与读数关系 | 对齐与闭环 | 对齐电流 300 mA、极对数 1、稳定 700 ms、步进 90°、上限 720°，勾选「自动写回 0x242」→ 开始对齐 | **R² > 0.99**；四组残差 < 5 counts；`0x242` 已写 | R² 低 → 回 A4 查编码器，或加大电流到 350 mA |
| **A6** | 第一次闭环 | 对齐与闭环 | 目标 100 RPM → 确认勾选 → 启动闭环 | 实际转速跟上目标（±10%）；无尖叫；电流不长期顶限幅 | 飞车/抖动 → 立刻急停 → 流程 D |
| **A7** | 确认参数不是野值 | PID 与限幅 | 「从芯片读取」，对照「生产参数对照」 | 电流环 64/48（Q8.8）；速度环 500/250；力矩限幅 800 mA | 不符 → 载入生产参数 → 重新写入 |
| **A8** | 装上丝杆后的保命环节 | 机械行程 | 见 **流程 C** | 越界自动停；运动被拒绝 | → 流程 C |
| **A9** | 验收留档 | 自动测试 | 见 **流程 E** | 全部档位 pass；CSV 已生成 | → 流程 E |

### 2.3 这一步最容易出的三个错

1. **跳过 A4 直接对齐**——对齐结果看起来"有数"，但 R² 其实很低，写回的偏移让后面所有环节都偏。
2. **用厂商默认的 10000 counts 对齐电流**——那是 ≈2 A，Tesla 电机只有 800 mA 限幅，会过热甚至消磁。
3. **A6 不把手放在急停上**——第一次闭环是最容易飞车的一步。

## 3. 流程 B：换电机 / 换编码器（重标定）

### 3.1 局部概览

```
 只换电机 ──▶ B1 填已知偏移(可选) ─▶ B2 重跑对齐 ─▶ B3 验证 R² ─▶ B4 低速闭环
 换编码器 ──▶ B0 全套重来(A3 起) ─▶ B2 ─▶ B3 ─▶ B4
 换驱动板 ──▶ 全套重来(流程 A)
```

**本章要点**：`0x242 电角度偏移`是**每台电机一对一**的，换电机必须重算；编码器或接线变了，连 A3 都要重做。

### 3.2 变化类型 → 要重做什么

| 只换了… | 重做编码器配置(A3) | 重做对齐(A5) | 重做 PID(D) | 重做行程(C) |
|---|---|---|---|---|
| 电机本体 | 否 | **是**（必须） | 建议 | **是**（行程会变） |
| 编码器 / 磁铁 | **是** | **是** | 否 | **是** |
| 驱动板 | **是** | **是** | 是（板子里的参数可能不同） | 否（除非原点丢） |
| 机械负载（同一台电机） | 否 | 否 | 建议 | **是** |
| 只换丝杆 | 否 | 否 | 否 | **是** |

### 3.3 分步执行

| 步 | 操作 | 判据 |
|---|---|---|
| **B1**（可选） | 编码器页「写入已知偏移」选对应 TMC_xx | 回读 `0x242` 与表一致 |
| **B2** | 对齐页：300 mA → 开始对齐 | 拿到新的 `offset` |
| **B3** | 看 R² 与四组残差 | R² > 0.99；残差 < 5 counts |
| **B4** | 100 RPM 闭环试转 | 跟随良好、无异响 |
| **B5** | 若机械也换了 → 走流程 C 重标行程 | 越界能停 |

> **B1 只是省时间，不能替代 B2**：遗留表里的偏移是当年那台电机的；先填进去可以快速验证方向对不对，最终仍以本次对齐结果为准。

## 4. 流程 C：装丝杆 → 行程标定 → 回零

### 4.1 局部概览

```
 C0 机械装配 ─▶ C1 手转全程 ─▶ C2 量导程/行程 ─▶ C3 接入位置反馈
                                                        │
   ┌────────────────────────────────────────────────────┘
   ▼
 C4 降力矩上限 ─▶ C5 慢速缩回到死点 ─▶ C6 停止+设原点 ─▶ C7 写软限位
                                                              │
                                    ┌─────────────────────────┘
                                    ▼
                        C8 点动验证 ─▶ C9 定位验证 ─▶ C10 恢复力矩上限
```

**本章要点**：C4 是安全前提（**当前软件的回零向导不带电流限制，必须手动先把 `0x14A` 降下来**）；C6 记录的原点必须是"停稳后"的位置；C8/C9 不通过就不要进产测。

### 4.2 分步执行

| 步 | 目的 | 入口 | 操作 | 判据 |
|---|---|---|---|---|
| **C0** | 装配到位 | 机械 | 丝杆、联轴器、导向、限位块全部装好并锁紧 | 手推滑块全程无卡滞、无异常摩擦 |
| **C1** | 确认有效行程 | 机械 | 手转电机，让滑块从一头走到另一头 | 记住两端"顶死"的手感位置 |
| **C2** | 得到两个关键数字 | 机械 | 卡尺量**导程**（转一圈走多少 mm）与**有效行程** | 导程 2 mm / 行程 20 mm（本例） |
| **C3** | 让软件看到位置 | 机械行程 | 「反馈通道 CH0」→ 点「接入位置反馈 0x155」→ 转轴看数值 | 大数字随转动变化；徽标变「反馈已就绪」 |
| **C4** | **把顶死的力矩降下来** | PID 与限幅 | 力矩限幅从 800 mA 改到 **200 mA** → 勾选确认 → 写入参数 | 回读 `0x14A` ≈ 993 counts（200 / 0.20131） |
| **C5** | 慢速找端点 | 机械行程 | 找零速度 20 RPM → 「① 关闭软限位」→「② 低速缩回」 | 滑块接近死点时转速明显下降、声音变沉 |
| **C6** | 记录原点 | 机械行程 | 观察到顶住且**位置不再变化**后「③ 停止」→「设为原点」 | 大数字归 0.000 mm；原点 counts 已锁定（不再显示"未锁定"） |
| **C7** | 建立保护窗口 | 机械行程 | 填导程 2 / 行程 20 / 边距 0.5 / 方向 → 「写入软限位」 | 徽标「软限位已写入」；行程条出现青色窗口 + 远端斜纹 |
| **C8** | 验证保护真的会停 | 机械行程 | 点动速度 30 RPM →「伸出」，一路走到接近远端 | 距上限 < 0.2 mm 时自动停、徽标「已触发」 |
| **C9** | 验证定位能用 | 机械行程 | 「复位触发」→ 目标 10 mm、速度上限 120 RPM →「定位」 | 停在 10.00 mm ± 容差；「到位」徽标出现 |
| **C10** | 恢复额定出力 | PID 与限幅 | 力矩限幅改回 800 mA → 写入参数 | 回读 ≈ 3974 counts |

### 4.3 关于"怎么知道到死点了"（当前限制）

现在的回零向导**只有转速，没有电流上限和到位判据**，所以 C5→C6 靠人：

| 你要观察的 | 正常 | 异常 |
|---|---|---|
| 实际转速（运行概览 KPI 或 RTMI） | 一直 ≈ 20 RPM，接触瞬间掉到 0–3 RPM | 中途就掉速 → 卡滞，不是到位 |
| 力矩电流 | 接触后升到 200 mA 限幅并保持 | 一直顶不到限流 → 没接触 / 电流上限设太高 |
| 位置数值 | 接触后**完全不动** | 还在缓慢变化 → 还在走 / 打滑 |

**判"到位"的三个条件同时满足**：① 转速掉到 <5 RPM 且不再回升；② 电流顶在限幅；③ 位置连续 200 ms 不变。三个都满足才按「③ 停止」。

> 软件后续会做「自动找零」（把上面三条变成自动判据 + 超时保护）。在此之前，**必须按 C4 先把力矩降到 200 mA**，否则 800 mA 顶着死点会顶坏丝母、并把弹性变形量记进原点。

### 4.4 行程参数怎么定

| 参数 | 取值方法 | 建议 |
|---|---|---|
| 导程 | 卡尺量：转 10 圈量位移 ÷ 10 | 常见 1/2/4/5/10 mm |
| 有效行程 | 两端死点之间的实际距离 | 用实测，不要用图纸标称 |
| 安全边距 | ≥ 定位超调的 2 倍，且 ≥ 0.3 mm | 0.5 mm 起 |
| 计数方向 | 点动"伸出"，看 counts 增大还是减小 | 反了就改下拉 |
| 速度上限 | 不让滑块在 50 ms 内走过边距 | 20 mm 行程用 120–300 RPM |

## 5. 流程 D：PID 整定

### 5.1 局部概览

```
 D1 读现值 ─▶ D2 电流环阶跃 ─▶ D3 判指标 ─▶ D4 写回 ─▶ D5 复测
                                              │
                                   ┌──────────┘
                                   ▼
                        D6 速度环阶跃 ─▶ D7 判指标 ─▶ D8 写回 ─▶ D9 联调
```

**本章要点**：**永远从内环到外环**；每一步写完必须复测；改不动就「载入生产参数」回滚。

### 5.2 分步执行

| 步 | 操作 | 判据 | 不达标 |
|---|---|---|---|
| **D1** | PID 页「从芯片读取」 | 记录当前 P/I/归一化/限幅 | 读失败 → 查通信 |
| **D2** | 阶跃测试：电流环 iD、500 mA、1500 ms、R=2.01 Ω、L=111.8 µH、带宽 2000 Hz | — | — |
| **D3** | 看阶跃响应四指标 | 上升 8–12 ms；超调 <5%；稳态误差 <2%；无明显纹波 | 见 5.3 调整表 |
| **D4** | 「应用到电流环」→ 勾选确认 → 写入参数 | 回读系数与界面一致 | 差异 → 重写 |
| **D5** | 再跑一次阶跃 | 指标复现 | 不复现 → 查限幅/采样率 |
| **D6** | 阶跃测试切「速度环」，幅度 300 RPM | — | — |
| **D7** | 看四指标 | 上升 <80 ms；超调 <10%；无持续振荡 | 见 5.3 |
| **D8** | 写入参数 | 回读一致 | — |
| **D9** | 回到「对齐与闭环」跑 100→300→600 RPM | 跟随误差 <5%；电流平稳 | 仍摆动 → 降速度环 P |

### 5.3 指标不达标怎么调

| 现象 | 调整 | 幅度 |
|---|---|---|
| 上升太慢 | 加 P | ±10~20% |
| 超调太大 / 振荡 | 降 P | −10~20% |
| 稳态误差大 | 加 I | +10~20% |
| 低频晃动、慢慢来回 | I 太大 | −20% |
| 高频尖叫 | P 太大 / 归一化错 | 先查 Q 格式 |

### 5.4 回滚

任何一步调坏：PID 页 → 「载入生产参数」→ 勾选确认 → 写入参数。这是唯一允许的"一键恢复"，**不要手改寄存器往回凑**。

## 6. 流程 E：出厂测试与报告

### 6.1 局部概览

```
 E1 填序列号 ─▶ E2 选档位 ─▶ E3 勾选确认+ARM ─▶ E4 开始测试
                                                      │
                                    ┌─────────────────┘
                                    ▼
                     E5 判读汇总 ──┬── 全 pass ──▶ E6 归档 CSV
                                   └── 有 warn ──▶ E7 复测或返修
```

### 6.2 分步执行

| 步 | 操作 | 判据 |
|---|---|---|
| **E1** | 序列号（必填，建议 `批次-工位-序号`）、操作员、备注 | 输入框下方不再出现"序列号必填" |
| **E2** | 档位表：默认 100/300/600/−300 RPM 各 3 s；容差 8%；间隔 1.2 s | 档位覆盖实际用的转速段 |
| **E3** | 勾选安全确认 → 顶栏 ARM | 「开始测试」可点 |
| **E4** | 开始测试 | 执行进度逐档刷新，无红字 |
| **E5** | 看「汇总」表 | 每档 verdict 全为 `pass` |
| **E6** | 「报告目录」→ 取 CSV | 文件名含序列号与时间戳 |
| **E7** | 有 `warn` | 先看是哪一档：低转速档 warn 多为摩擦/低速控制差；高速档 warn 多为限幅或带宽 |

### 6.3 CSV 用法

| 列 | 用途 |
|---|---|
| `t_ms` | 时序对齐 |
| `target_rpm` / `actual_rpm` | 画跟随曲线、算超调 |
| `current_ma` | 判断是否长期顶限幅（效率/摩擦） |
| `temp_c` | 长时测试看温升（未校准时为 0） |

## 7. 流程 F：故障恢复

### 7.1 局部概览

```
 发生异常 ─▶ F0 先保人保机械 ─▶ 判定属于哪一类
                                   ├─ 急停后   → F1
                                   ├─ 越限触发 → F2
                                   ├─ 通信中断 → F3
                                   └─ 参数写坏 → F4
```

**原则：先停、再看、后恢复。恢复后必须重新验证那一步的判据，不许"看起来好了"就继续。**

### 7.2 F1 急停之后

| 顺序 | 动作 | 说明 |
|---|---|---|
| 1 | 断电/断开电机电源 | 急停只是软件 PWM_OFF，**不断电仍可能有余电/重力下落** |
| 2 | 看日志的 `[safety]` 行 | 确认是急停还是软限位触发的 |
| 3 | 排查触发原因 | 飞车？过流？越界？误触？ |
| 4 | 重新连接 → 读 `0x009` 故障位 | 有故障位先按手册清 |
| 5 | 从 A2 开始重新核对 | **不要直接跳到闭环** |
| 6 | 低速试转确认 | 100 RPM 跟随正常再继续 |

### 7.3 F2 软限位触发之后

| 顺序 | 动作 |
|---|---|
| 1 | 确认滑块没有顶死（手能推动一点点） |
| 2 | 机械行程页看「上次触发」的 counts 与方向 |
| 3 | 判断：是正常走到位（假报警）还是参数错（原点/导程/方向） |
| 4 | 参数错 → 重新回零（流程 C 的 C4~C7） |
| 5 | 参数对 → 「复位触发」 |
| 6 | 点动 30 RPM 反向走开，确认能脱离限位区 |

### 7.4 F3 通信中断之后

| 现象 | 动作 |
|---|---|
| 日志大量 `Timeout` / 丢弃字节增长 | 降采样率或提波特率；换短 USB 线；避开强干扰源 |
| 串口打不开 | 关掉厂商控制台/串口助手；查驱动与端口号 |
| 连上但读不到 `CHIP.ID` | 换波特率 115200 ↔ 921600；查 TX/RX 与共地 |
| RTMI 突然停止 | 看是否有人点了「停止」；看 `UART.CONTROL` 的 bit22 |

### 7.5 F4 参数写坏之后

| 顺序 | 动作 |
|---|---|
| 1 | **立刻停转**（停止/急停） |
| 2 | PID 页「载入生产参数」→ 写入 |
| 3 | 编码器页「刷新回读」核对 `0x240/0x250/0x0C3/0x103` |
| 4 | 确认 `0x242` 是否还在（对齐偏移没被覆盖） |
| 5 | 从 A5/A6 重新验证 |

## 8. 判据总表

| # | 阶段 | 判据 | 在哪看 | 不达标怎么办 |
|---|---|---|---|---|
| 1 | 通信 | 日志出现 `CHIP.ID = 0x64600001` | 运行日志 | 换波特率/查线序（F3） |
| 2 | 编码器写入 | 写入校验表 5 行全 OK | 编码器页右下 | 重写；查写保护（A3） |
| 3 | 编码器写入 | `0x0C3` 回读 = 3（4×） | 写入校验表 | 重写；遗留固件会写成 0 |
| 4 | 编码器读数 | `PHI_EXT_A ≠ 0`，手转时明显变化 | 角度回读卡 | 查 SCK/SDO/CSN、`u[7]`、预设（A4） |
| 5 | 对齐质量 | R² > 0.99 | 对齐结果卡 | 加大电流/查编码器打滑（A5） |
| 6 | 对齐一致性 | 四组残差 < 5 counts | 对齐结果卡 | 同上 |
| 7 | 闭环跟随 | 实际/目标偏差 < 10%（低速） | 速度闭环卡 | 流程 D |
| 8 | 闭环电流 | 不长期顶 800 mA 限幅 | 运行概览 KPI | 查摩擦/限幅/增益 |
| 9 | PID 参数 | 电流 64/48 Q8.8；速度 500/250 | PID 页 | 载入生产参数 |
| 10 | 力矩限幅 | 正常 800 mA；回零时 200 mA | PID 页 | 按阶段设置 |
| 11 | 位置反馈 | CHx 数值随转动变化 | 机械行程页 | 点「接入位置反馈 0x155」 |
| 12 | 原点 | 大数字 = 0.000，原点已锁定 | 轴状态卡 | 重做 C6 |
| 13 | 软限位 | 徽标「软限位已写入」 | 轴状态卡 | 先接反馈再写（C7） |
| 14 | 越界保护 | 接近远端自动停并「已触发」 | 机械行程页 | 查导程/方向/原点（C8） |
| 15 | 定位 | 停在目标 ± 容差且「到位」 | 机械行程页 | 降速度上限；查边距（C9） |
| 16 | 产测 | 全档位 pass | 自动测试汇总 | 按档位排查（E7） |
| 17 | 采样质量 | 丢弃字节 = 0 | 示波器底部 | 降采样率/提波特率 |

```

□ 力矩限幅临时降到 200 mA → 低速回零 → 设原点

□ 定位 10 mm 到位
□ 力矩限幅恢复 800 mA
```

### 9.2 每次产测（贴工位用）
