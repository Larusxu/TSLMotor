## 1. 这个软件能做什么

TSL Viewer 是这套 TMC6460 + MT6701 + 丝杆机构的专用上位机，把原来分散在**厂商控制台**、**遗留 PyQt 上位机**和**手工寄存器操作**里的工作合并到一个窗口：

| 能力 | 说明 |
|---|---|
| 串口直连 | 打开 TMC6460 的 UART，自动读 `CHIP.ID` 确认板子在线 |
| 寄存器全览 | 189 个寄存器按地址/名称/中文标签搜索，支持位编辑与写后回读校验 |
| 编码器配置 | MT6701 SSI 帧参数一键下发，并逐寄存器核对期望值与实际值 |
| 电角度对齐 | 开环电流拖动转子、4 点拟合，自动算 `0x242` 并写回 |
| 闭环试转 | 速度环闭环运行，实时看转速/电流跟随 |
| PID 调参 | 电流/速度/位置三环 Q 格式系数、限幅、阶跃响应实测与建议值 |
| 机械行程保护 | 丝杆导程换算、软限位（每帧检查）、点动/定位、回零向导 |
| 实时示波器 | 最多 4 路 RTMI 通道，2/5/15/60 秒窗口，游标读数 |
| 自动测试 | 多档位转速序列 + 判据 + CSV 报告 |
| 全链路日志 | 串口、任务、保护动作全部留痕，可过滤导出 |

**它不做的事**：不做芯片固件升级；不做 Modbus/网络转发；不做多轴联动（一次控制一台电机）。

## 2. 安装与启动

### 2.1 运行方式

| 方式 | 适用场景 | 操作 |
|---|---|---|
| 启动脚本 | 源码目录调试（推荐） | 双击 `scripts\start.bat` 或运行 `scripts\start.ps1`，直接启动已构建的桌面程序（不编译、不打包） |
| 安装包 | 产线/调试电脑长期使用 | 双击 `TSL Viewer_0.1.0_x64-setup.exe` → 安装 → 开始菜单启动 |
| 免安装 | 临时借用电脑 | 直接运行 `src-tauri/target/release/tslviewer.exe` |
| 浏览器预览 | 无硬件时看界面、培训 | 源码目录执行 `npm run dev`，打开 `http://localhost:5183` |

> 浏览器预览模式**没有串口权限**，软件会自动切到内置模拟器（虚拟 COM6、`CHIP.ID = 0x64600001`、正弦转速/电流）。
> 判断方法：看侧栏底部「构建」字段——`desktop` 是真实应用，`preview` 是模拟。

### 2.2 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 1809 及以上 / Windows 11（需要 WebView2，未装会在安装时自动补） |
| 屏幕 | 建议 1440×900 及以上；最小 1120×700 |
| 串口 | 板子的 USB 转串口（CH340/CP210x/FTDI），需先装对应驱动 |
| 权限 | 无需管理员（除首次安装） |

### 2.3 数据落盘位置

| 内容 | 路径 |
|---|---|
| 测试报告 CSV | `%USERPROFILE%\Documents\TSLViewer\reports\` |
| 配置/参数 | 不落盘，全部保存在芯片里（软件每次上电重新读取） |

> 报告目录：自动测试页右上角「报告目录」按钮直接用资源管理器打开。

### 2.4 首次启动建议

1. 先不接电机电源，只接 USB；
2. 打开软件 → 选串口 → 点「连接」；
3. 看日志里是否出现 `CHIP.ID = 0x64600001`；
4. 确认通信正常后再上电机电源。

## 3. 界面总览

```
┌──────────────────────────────────────────────────────────────────────┐
│ 顶栏：TSL / 页面代号 │ 连接状态 │ 串口 │ 波特率 │ 刷新 │ 连接/断开 │ ARM │ 急停 │
├────────┬─────────────────────────────────────────────────────────────┤
│ 侧栏   │ 页面标题 + 一句话说明                                        │
│ ·工作区│                                                              │
│ ·调校  │   卡片区（每页 2~4 列，卡片高度按内容自适应）                 │
│ ·生产  │                                                              │
│ 底部   │                                                              │
│ 链路…  │                                                              │
└────────┴─────────────────────────────────────────────────────────────┘
                                          Toast 提示（右下角，3 秒自动消失）
```

### 3.1 顶栏

| 元素 | 说明 |
|---|---|
| `TSL / OVERVIEW` | 面包屑，显示当前页代号 |
| 连接徽标 | 灰=离线，绿点=已连接 |
| 串口下拉 | 列出系统串口（如 COM11），点右边的刷新按钮重新枚举 |
| 波特率下拉 | 115200 / 230400 / 460800 / 921600 / 1.5M / 2M / 3M。**默认 115200 只能跑约 1 kHz 单通道**，见 3.4 |
| 连接 / 断开 | 连接时自动读一次 `CHIP.ID`；断开时**先执行急停**再关串口 |
| ARM 开关 | 安全解锁。所有会让电机动作的按钮都要求先打开它 |
| 电机 `M1…M16` | 仅主控模式显示，在 ARM 右侧。**连接状态下也能切换**：切走会先停采集、重新申请目标电机通道，旧软限位/标定需重新确认 |
| 使能（红/绿） | 紧邻电机下拉。点击即给该电机上逻辑 5V 并轮询 `CHIP.ID`：读到了变绿「已使能」，读不到保持红「未使能」。需连接 + ARM |
| 急停（红色） | 立即写 0 目标 → PWM_OFF → 清驱动使能，并终止正在跑的任务 |

### 3.2 侧栏

| 分组 | 页面 | 代号 |
|---|---|---|
| 工作区 | 运行概览 | RUN / OVERVIEW |
| | 编码器 | SSI / ENCODER |
| | 对齐与闭环 | PHI_E / CLOSED LOOP |
| | 机械行程 | AXIS / TRAVEL GUARD |
| 调校 | PID 与限幅 | TUNE / TUNING |
| | 寄存器 | MAP / REGISTER MAP |
| 生产 | 自动测试 | QA / SEQUENCE |
| | 运行日志 | LOG / LOGS |

底部四个状态：**链路**（端口号）、**帧率**（RTMI 实测帧/秒）、**PWM**（由 `0x103` 反算）、**构建**（desktop / preview）。

### 3.3 页面通用交互

- 卡片标题右侧常放「业务按钮」（写入、读取、切换），左侧是中文名 + 英文小字代号。
- 字段标签右侧的灰色小字是**寄存器名或换算提示**（如 `0x242`、`half=14 → 2.00 MHz`）。
- 数值输入框带单位后缀（`mA`、`RPM`、`mm`、`µH`），超出范围会被夹到边界。
- 右下角 Toast：绿色=成功、黄色=警告、红色=错误，鼠标移上去不消失，3 秒后自动走。

### 3.4 关于波特率与采样率

RTMI 每个通道每帧占 5 字节（开 CRC 则 6 字节）。

| 波特率 | 4 通道 × 5 B 的单帧耗时 | 建议最高采样率 |
|---|---|---|
| 115200 | ≈ 1.7 ms | 500 Hz（3 通道可到 1 kHz） |
| 921600 | ≈ 0.2 ms | 4 kHz |
| 2000000 | ≈ 0.1 ms | 4 kHz 以上 |

运行概览页的黄色提示会实时算给你看。**看到「丢弃字节」不为 0，就先降采样率或提波特率。**

## 4. 单位与术语

| 术语 | 含义 | Tesla 平台的数 |
|---|---|---|
| counts（LSB） | 芯片内部计数单位 | 位置每圈 65536；速度 305.4 counts/RPM |
| CPR | 编码器每圈脉冲数 | 16384（×4 解码后 65536） |
| mA/LSB | 电流分辨率 | 0.20131 mA/LSB，8192 LSB = 1.65 A |
| RPM | 机械转速 | — |
| Q 格式 | PID 系数的定点缩放 | 电流环默认 Q8.8（Shift by 8） |
| RTMI | 芯片的实时数据流（读寄存器推送） | 触发率 = fPWM / (sampling+1) |
| φ_e | 电角度 | 16 位对应 0–360° 电角 |
| 软限位 | 软件层的行程保护 | 见第 7 章 |

**换算公式**（页面上都已内置，这里供核对）：

```
转速：RPM = 速度寄存器值 / 305.4
电流：mA  = LSB × 0.20131
位置：度  = counts / 65536 × 360
丝杆：mm  = counts / (65536 / 导程)
力矩限幅 counts = mA / 0.20131
```

## 5. 第一次上电：九步流程

> 顺序不能跳。每一步都要看结果再往下走。

| 步骤 | 页面 | 做什么 | 通过标准 |
|---|---|---|---|
| ① 接线自检 | — | 电机固定、联轴器/丝杆锁紧、电源限流 | 手转电机无卡滞 |
| ② 连接 | 顶栏 | 选串口 → 连接 | 日志出现 `CHIP.ID = 0x64600001` |
| ③ 读现状 | 运行概览 | 看 KPI 与「驱动状态」卡 | 运动模式、极对数、供电 VM 合理 |
| ④ 编码器 | 编码器 | 选预设 → 写入 → 刷新回读 | 写入校验表 5 行全 OK；手转电机角度变化 |
| ⑤ 电角度对齐 | 对齐与闭环 | 300 mA 对齐 → 开始对齐 | R² > 0.99，偏移已写回 `0x242` |
| ⑥ 低速闭环 | 对齐与闭环 | 100 RPM 试转 | 实际转速跟得上、无异响、电流不顶限幅 |
| ⑦ PID 核对 | PID 与限幅 | 「从芯片读取」对照生产参数 | 电流环 64/48（Q8.8）、速度环 500/250 |
| ⑧ 行程保护 | 机械行程 | 回零 → 写软限位 → 点动验证 | 越界自动停、运动被拒绝 |
| ⑨ 出厂测试 | 自动测试 | 填序列号 → 跑序列 | 全部档位 pass，CSV 已生成 |

> ⚠️ 第 ④ 步之前**不要**做第 ⑤ 步：编码器没配好，对齐拟合会得到一堆噪声，写回去的偏移反而更糟。

## 6. 页面详解

### 6.1 运行概览

**用途**：一眼看清当前状态；做实时波形观察与手动速度运行。

**顶部 4 个 KPI**

| 卡片 | 显示 | 数据来源 |
|---|---|---|
| 实际转速 | RPM | 采集时用 RTMI 实时值，未采集时直读 `0x154` |
| 目标转速 | RPM | RTMI 值或 `0x150 / 305.4` |
| 力矩电流 iQ | mA | `0x153`，副标题给出占 800 mA 限幅的百分比，>700 mA 变黄 |
| 结温 | °C | `0x084`；原始值为 0 表示 NTC 未接/未校准，显示「—」 |

**实时遥测卡**

| 控件 | 说明 |
|---|---|
| `2s / 5s / 15s / 60s` | 时间窗，只影响显示，不改采集 |
| 暂停 / 继续 | 冻结画面（数据仍在后台记录） |
| 开始采集 / 停止 | 启动 RTMI（按「信号通道」卡的配置） |
| 曲线区 | 鼠标移入出现十字游标，左下角图例显示每通道瞬间值 |
| 底部状态 | 帧率、触发频率、sampling 值、丢弃字节数 |

**信号通道卡**

| 控件 | 说明 |
|---|---|
| CH0–CH3 | 每个通道映射一个观测量（实际转速/目标转速/电流/位置/电角度/温度…） |
| 采样率 | 250 / 500 / 1000 / 2000 / 4000 Hz，实际 sampling = fPWM/采样率 − 1 |
| 同步 | 目前固定 PWM_Z 起点 |
| 黄色提示 | 按当前波特率与通道数算出的最小帧间隔，超了就丢字节 |

**手动运行卡**

| 控件 | 说明 |
|---|---|
| 目标转速 | −3000…3000 RPM，可正反转 |
| 确认勾选 | 「我已确认电机固定、电源限流」 |
| 启动 | 软限位已写入时走**受保护点动**（越界会被拒绝）；未写入时直通芯片 `set_velocity` |
| 停止 | 写 0 目标并 PWM_OFF |

**底部三卡**：驱动状态（模式/极对数/使能/VM/电流矢量/状态字 + 重新读取 + 使能驱动）、故障位（`0x009` 解码）、机械常数（极对数、PWM MAX_COUNT、mA/LSB、counts/RPM 等，只读展示）。

> 「使能驱动」按钮写 `0x101` 的 `DRV_EN` + 电荷泵位，属于带电操作，必须先 ARM。

**页面最底部：TeslaHand 主控卡（仅主控模式）**

| 控件 | 说明 |
|---|---|
| 读取 16 路映射 | 读主控固件版本 + 16 路 DTS 路由（UART / 供电支路 / 主控就绪 / 逻辑供电），随后自动跑一次 TMC 探活 |
| 检测 TMC | 只重跑探活：逐路切到目标电机读 `CHIP.ID`，失败最多轮询 6 次。采集进行中会被拒绝，先停采集 |
| 当前电机逻辑上电 / 断电 | 对顶栏选中的电机发 op5；上电需要 ARM（无二次确认弹窗，点了就下发） |
| 全部逻辑断电 | op6，一次性关掉 16 路逻辑 5V |
| 表格 | **双栏**：左 M1–M8，右 M9–M16。列为「电机 / 主控 UART / 逻辑供电 / TMC」，当前电机行高亮 |

- `主控 UART` 列合并了原来的 UART 号与就绪位，显示成 `UART11-就绪`。
- `TMC` 列只有**真的读到 `CHIP.ID` 才算在线**；没上电、没接线、UART 未就绪都会显示「掉线」，未检测显示「—」。
- 卡片右上角徽标是 `在线/已检测` 计数（如 `1/16 在线`），固件版本以等宽字体显示在同一行。

### 6.2 编码器

**用途**：把 MT6701 的 SSI 参数正确写进芯片，并当场验证。

**左列 · 编码器参数**

| 字段 | 提示 | 说明 |
|---|---|---|
| 预设 | 选择后自动填充 | `MT6701 · SSI 14-bit（台架已验证）` / `… 24-bit 完整帧` |
| 极对数 | PHI_E_MUL_FACTOR | Tesla = **1** |
| 编码器步数 CPR | — | 16384（对应 65536 counts/圈） |
| 电角度偏置 | 0x242 | 16 位。勾选「初次电角度偏置标定」时置灰、显示「待对齐」；选遗留表或手动时才可编辑 |
| 写入已知偏移 | 遗留表 | 首项「初次电角度偏置标定」并**默认选中**（本步不写 0x242）；选 TMC_01…TMC_18 会取消勾选并按该机历史偏移写入；选「— 手动 —」则用左侧框里的值 |
| 帧长度 | SPI_BIT_CNT | 14 bit（只取角度）/ 24 bit（含状态+CRC） |
| SPI 模式 | CPOL/CPHA | MT6701 固定 **模式 1**（时钟上升沿更新、下降沿采样） |
| SCK 频率 | half=n → x.xx MHz | 14 bit 预设是 2 MHz（half=14） |
| CSN 间隔 | SPI_CSH_CNT · 自动读取率 | 帧间等多少个 60 MHz 系统时钟；**空闲时间与计数的平方成正比且最短 6 µs**（手册 p.115），16 ≈ 7.5 µs。**标签右上角会自动算出当前采样率**（如 `≈68.8 kHz 读取率`），随帧长度 / SCK 频率 / 本值实时变 |
| 数据掩码 | RESPONSE_2 · 随帧长度 | **只读派生**：14 bit → `0x00003FFF`；24 bit → `0x00FFFFFF`。由「帧长度」自动算出（`2^位长 − 1`），不再手填 |
| 发送数据 | RESPONSE_1 | 通常 `0x00000000` |
| PWM MAX_COUNT | fPWM = 120 MHz / n | 4800 → 25 kHz。**改它等于改整个控制环时基**，非必要不要动 |
| CSA 增益 | 0=1× · 3=4× | Tesla = 3（4×，0.20131 mA/LSB，满量程 ±1.65 A）；下拉会同时标出每档的满量程与 mA/LSB |
| `u[7]=1 · CS 走 ENC_N` | 复选框 | 用 ENC_N 引脚当片选，台架已验证 |
| 同时写入速度测量配置 | 复选框 | 一并写 `0x244/0x245`，两行 HexField 会展开 |
| 初次电角度偏置标定 0x242 | 复选框 | **默认勾选**。勾选 = 本步**不写** `0x242`（新电机/新磁铁必须如此），偏移由「对齐与闭环」测得；取消勾选才会把左侧框的值写进芯片 |
| 确认写入 IO_MATRIX… | 复选框 | **必勾**。写入会立即改变引脚复用，勾选是二次确认 |
| 写入编码器配置 | 主按钮 | 12 步流程，右侧「配置流程」卡实时显示每步结果 |
| 刷新回读 | 次按钮 | 只读回当前值，不写 |

**右列 · 角度回读**

- **这一步就是"手转轴验证"（流程 A4）**：不用点任何按钮，只要已连接，卡片每 260 ms 自动刷新——用手慢慢转电机轴一圈，`MECHANICAL` 应从 0° 连续走到 360° 再回 0°，`PHI_EXT_A` 原始值同步变化。
- 两个仪表：`MECHANICAL`（机械角，来自 `PHI_EXT_A`）与 `ELECTRICAL`（电角度 `PHI_E`）。
- 明细：`PHI_EXT_A` 原始值、缩放后 16-bit、电角度 16-bit、`CPR_INV`、`PHI_E_MUL_FACTOR`。
- 黄色警示：**`PHI_EXT_A = 0` 表示没读到编码器**——查 SCK/SDO/CSN 接线、`u[7]` 选择、预设是否匹配。

**写入校验表**：把 `0x240 / 0x250 / 0x242 / 0x0C3 / 0x103` 的期望值与回读值并列，OK/差异一目了然。出现「差异」先不要继续对齐。勾选「初次电角度偏置标定」时，`0x242` 那一行的期望值显示 `—`、结论显示 **待对齐**，表示该值将在下一步骤测得。

**手册依据**：SPI_ENC 命令位域（p.114）、MT6701 24 拍帧格式、16 位换算公式（p.180）、CSA 增益注意事项。

**这一段最容易踩的坑**

1. `0x0C3` **复位默认是 0（1×）**，而遗留固件与旧上位机都显式写 3（4×）。手表没写成功就会静默跑在 1×：**读数刻度不变（0.20131 mA/LSB）**，但裁切点从 `2¹⁵/4 = 8192` counts（±1.65 A）变成 32768 counts（±6.60 A），小电流精度变差——按 8192 当满量程的保护/校验会失准，务必看回读。
2. 24 bit 帧会让 `PHI_EXT_A` 变成 24 位原始字，`CPR_INV` 的算法与 14 bit 不同；不确定就用 14 bit 预设。
3. 写入会改 `IO_MATRIX`，每次写都要重新读一次「角度回读」确认编码器还有数。

## 7. 机械行程与软限位（专章）

### 7.1 为什么需要它

电机空转验收时，转多少圈都无所谓；一旦接上丝杆，两端就有**不能撞的机械死点**。撞上去轻则丝母磨损、皮带跳齿，重则顶坏联轴器或丢步导致位置永久错位。软限位就是"在撞之前先把闸拉下来"。

### 7.2 位置是怎么来的

芯片的 `0x155 FOC.PID_POSITION_ACTUAL` 只有 **16 位，每圈归零**。20 mm 行程 / 2 mm 导程 = 10 圈 → 这个寄存器会回绕 10 次，**直接拿它做限位一定会误判**。

软件在接收每一帧时把相邻两帧的差值累加，展开成连续的 32 位位置：

```
Δ = raw[n] − raw[n−1]
Δ > 32768  → Δ −= 65536      （正向跨零）
Δ < −32768 → Δ += 65536      （反向跨零）
pos += Δ
```

前提：相邻两帧位移不超过半圈。1 kHz 采样下半圈/帧 = 500 转/秒 = 30000 RPM，远高于 25 000 RPM 上限，所以不会误判。

### 7.3 窗口语义

```
机械 0mm                                                     行程 20mm
  │                                                              │
  ├──────────────── 可运动窗口 ──────────────┼── 安全边距 0.5mm ──┤
  原点                                     软限位上限         机械死点
```

- **近端 = 原点本身**：归零后电机就停在这儿，如果近端还要扣边距，一上电就"站在窗口外"，保护反而写不进去。
- **安全边距从远端扣**：远端才是会撞的那一侧。

### 7.4 生效链条

| 环节 | 动作 |
|---|---|
| 写入前 | 后端校验「该通道是否正在采位置」，否则拒绝写入 |
| 目标下发前 | `定位` 目标不在窗口内 → 直接拒绝 |
| 运行中 | RTMI 线程**每收到一帧**比对一次（1 kHz 级），越界立刻停 |
| 越限动作 | `松力矩` = 写 0 目标 + 清积分器保持；`刹车` = PWM_OFF + 清 DRV_EN |
| 反馈中断 | `点动/定位` 直接返回错误——**宁可不走，也不盲走** |
| 触发后 | 进入锁定态，运动被拒；点「复位触发」才恢复 |

### 7.5 归零顺序（少一步都不安全）

1. 编码器配好、角度回读正常；
2. 接入位置反馈（CHx = `0x155`），确认数值随转动变化；
3. 关软限位 → 慢速缩回 → 顶到机械限位 → 停止；
4. 「设为原点」→ 填导程/行程/边距 → 「写入软限位」；
5. 10% 速度点动一次，确认接近限位时会自己停；
6. 再做定位，**第一次一定低速**。

### 7.6 软限位做不到的事

- 依赖位置反馈：反馈断了就不保护（此时软件**拒绝运动**）。
- 不能替代机械限位块、硬件急停回路、抱闸。
- 上电后未回零前，窗口是"未写入"状态，此时命令不受限位约束。

## 8. PID 调参手册

### 8.1 三环级联关系

```
位置环(0x146) ──输出→ 速度环(0x145) ──输出→ 电流环(0x142/0x143) ──输出→ SVPWM
   慢                         中                         快
```

调参顺序**永远从内到外**：先电流环，再速度环，最后位置环。

### 8.2 Q 格式：最容易翻车的地方

寄存器里存的是整数，真实增益 = 整数 × 2^(−frac)。

| 归一化 | 缩放 | 例子 |
|---|---|---|
| `No shift（Q16.0）` | ×1 | 出厂默认，整数就是增益 |
| `Shift by 8 / Q8.8` | ÷256 | 64 → Kp 0.25 |
| `Shift by 16 / Q0.16` | ÷65536 | 500 → Kp 0.0076 |

**把 64/48 这种"Q8.8 整数"写进 Q16.0，实际增益放大 256 倍**——这就是烧管子的最短路径。

### 8.3 用阶跃法整定

1. 「从芯片读取」拿到当前值；
2. 选「电流环 iD」，幅度 500 mA，时长 1500 ms，填 R=2.01 Ω、L=111.8 µH、带宽 2000 Hz；
3. 勾选确认 → 执行阶跃；
4. 看指标：
   - 上升时间 8–12 ms、超调 < 5%、无稳态误差 → 合格；
   - 超调大 → P 降 10–20%；
   - 上升慢、稳态不收敛 → I 加 10–20%；
5. 「应用到电流环」→ 写参数 → 复测一次。

### 8.4 症状对照表

| 现象 | 先查 | 处理 |
|---|---|---|
| 一给转速就尖叫、电流顶限幅 | 电流归一化是否 Q8.8 | 改归一化或把 P/I 除以 256 |
| 转速上不去、稳态差很多 | `0x14A` 力矩限幅、`0x149` 电压限幅 | 800 mA / 23169 是否被清零 |
| 300 RPM 目标实测 200–330 摆动 | 速度环 P 偏大、测速更新率 | 降速度环 P 至 300，提采样率 |
| 位置停在目标附近来回抖 | 位置环 P 太大、死区太小 | 降 P，或加位置容差 |
| 转向相反 | `PHI_E_MUL_FACTOR`、接线 | 先确认编码器方向，不要用 PID 硬掰 |

### 8.5 建议起点（Tesla 平台）

| 环 | P | I | 归一化 |
|---|---|---|---|
| 电流 | 64 | 48 | Shift by 8 / Q8.8 |
| 速度 | 500 → 摆动就降到 300 | 250 | Shift by 8 |
| 位置 | 500 | 0 | Shift by 8 |

## 9. 自动测试与报告

### 9.1 CSV 字段

| 列 | 含义 |
|---|---|
| `t_ms` | 相对时间（ms） |
| `target_rpm` | 目标转速 |
| `actual_rpm` | 实际转速 |
| `current_ma` | 力矩电流 |
| `temp_c` | 芯片结温（未校准则为 0） |

汇总表另含：窗口名、样本数、均值、标准差、纹波%、平均/最大电流、最高温度、结论。

### 9.2 判据

每档取后半段稳定窗口，`|均值 − 目标| / |目标| ≤ 容差` 判 pass；转速为 0 的档位记 `idle`；其余记 `warn`。

### 9.3 命名与归档

`reports\<序列号>_<yyyyMMdd-HHmmss>.csv`。建议序列号按 `批次-工位-序号` 编，便于追溯。

## 10. 寄存器页的三种用法

| 用法 | 操作 |
|---|---|
| 查状态 | 搜索地址 → 看「当前值」和位域表；只读寄存器只能读 |
| 改单个位 | 二进制网格点一下要翻的位 → 确认「待写入」→ 写入（自动回读校验） |
| 对照快照 | 先「刷新」记下值，改完再刷新一次对比；`与芯片一致 / 未写入` 徽标直接告诉你有没有写进去 |

> 不熟悉的寄存器**先读不写**。写之前确认：地址对不对、位域含义、是否需要保持其它位（很多寄存器是读-改-写，直接整字覆盖会清掉别的配置）。

## 11. 安全规范

1. **ARM 门禁**：对齐、闭环、序列、点动、定位都必须先 ARM；`停止` 与 `急停` 永远可用。
2. **急停三步**：写 0 目标 → PWM_OFF → 清 DRV_EN，同时置位取消标志终止任务。
3. **写后回读**：所有关键写入都回读校验，不一致在日志标 warn。
4. **任务互斥**：同一时刻只允许一个长任务，可随时取消。
5. **行程保护**：装丝杆必须开软限位；反馈中断时拒绝运动。
6. **不要用软件限位替代硬件**：机械限位块、硬件急停、断电开关是最后一道防线。
7. **第一次上电**：电源限流、电机固定、手放急停上、从 10% 速度开始。

## 12. 故障排查

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 串口打不开 | 被别的软件占用 / 驱动没装 | 关掉厂商控制台与串口助手；设备管理器看驱动 |
| 连接成功但读不到 `CHIP.ID` | 波特率不对 / TX-RX 接反 / 板子没上电 | 换 115200 ↔ 921600 试；查线序 |
| `PHI_EXT_A = 0` | SCK/SDO/CSN 接线、`u[7]` 选择、预设不匹配 | 查接线；试 14-bit ↔ 24-bit 预设；确认 IO_MATRIX |
| 写入校验表出现「差异」 | 写保护、地址错、芯片未进配置态 | 看日志的 error 行；重试「刷新回读」 |
| 电流读数看着偏 / 量程只剩一半 | `0x0C3` CSA 增益是 0（1×，复位默认）而不是 3（4×） | 编码器页重写，确认回读 `0x00000003`；刻度仍是 0.20131 mA/LSB，变的是裁切点 |
| 对齐 R² < 0.99 | 编码器打滑、极对数错、SPI 掩码错、电流太小 | 按顺序排查；加大到 350 mA 重试 |
| 闭环一转就飞车 | PID 归一化错、编码器方向反、`0x14A` 限幅过大 | 立刻急停；核对 Q 格式与编码器方向 |
| 转速波动 ±20% | 速度环 P 偏大、采样率太低 | 降 P、提高波特率/采样率，或做阶跃重调 |
| 采集曲线一片空白 + 丢弃字节增长 | 采样率超过串口带宽 | 降到 500 Hz 或提波特率到 921600 |
| 软限位写不进去 | 位置反馈没启动 / 当前位置在窗口外 | 先「接入位置反馈 0x155」，再确认原点 |
| 软限位老触发 | 原点设错、导程填错、方向反了 | 重新回零；核对导程与计数方向 |
| 点动没反应 | 未 ARM / 未勾选确认 / 已触发锁定 | 看按钮灰不灰；点「复位触发」 |
| 定位超调撞限位 | 速度上限太高、加速度太小 | 降速度上限，或提高加速度 |
| 日志刷不出内容 | 「跟随」被暂停、级别过滤掉了 | 点「跟随中」，切「全部」 |

## 14. 已知限制

1. **未在真机验证**：所有"实测值"来自遗留台架记录与手册公式；协议层由单元测试保证，但首次上电仍要按第 5 章走一遍。
2. **软限位是软件保护**：依赖位置反馈，不能替代硬件安全回路。
3. **24-bit 帧 CRC** 只做显示，不做纠错；报警位 `Mg[3:0]` 已在编码器页展示但未参与故障矩阵。
4. **电流环自整定**只给建议值，不自动辨识 R/L（芯片本身无阻抗测量功能）。
5. **温度**需外部校准（`0x084 = 0` 表示 NTC 未接）。
6. **单轴**：一次只能连一台 TMC6460。
7. 浏览器预览模式（`构建 = preview`）不产生任何串口流量，所有数据是模拟的，**不能用于验收**。
